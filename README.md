## 1. AI를 활용한 나만의 운동 일정관리 플랫폼 "Pebble.it"(Team쏜)

### 📌프로젝트 커밋 규칙📌
1. 매일 **오전 9시(주말포함) PULL📤** 받은 후 개발 진행하기
2. 매일 **회의를 통해 각자 수정할 파일📝 정하고,** 
   다른 사람이 수정하기로 한 파일을 수정할 때는 그 사람과 **협의하여 작업 진행**하기
3. **한가지 기능이 완료되면 COMMIT하여 최신화 후 PUSH 진행🎊**
4. **PUSH하기 전에 꼭 팀원들에게 이야기**하고 **✨확인했다는 피드백✨**을 받은 후 진행하기(어떤 파일의 어떤 기능인지 알려주기)
5. 커밋 메시지는 슬랙의 **커밋 메시지 규칙**을 참고하여 규칙에 맞게 올리기
6. 단기간에 구현을 해야 하므로 오랜시간 에러가 나거나 막히면 **✨빨리 팀원들에게 말해서 함께 문제 해결하기✨**
